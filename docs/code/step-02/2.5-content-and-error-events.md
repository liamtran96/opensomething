## `crates/bot-protocol/src/event.rs`

### 1. Three variants in `EventKind`

Add between `TurnStarted,` and the comment of `TurnCompleted`:

```rust
    /// The next piece of text. It is for the live display only: the reply to
    /// keep is the text of `item.completed`.
    #[serde(rename = "content.delta")]
    ContentDelta {
        stream_kind: StreamKind,
        delta: String,
    },

    /// The full text of the reply, sent one time when the engine completes it.
    #[serde(rename = "item.completed")]
    ItemCompleted { text: String },

    /// Why the turn failed. It does not end the turn: a `turn.completed` with
    /// the outcome `failed` follows.
    #[serde(rename = "runtime.error")]
    RuntimeError { code: ErrorCode, message: String },
```

Keep one empty line above and below these lines.

### 2. Two enums

Add above the comment `/// How a turn ended.`:

```rust
/// What a piece of streamed text is.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum StreamKind {
    /// Text of the reply.
    AssistantText,
    /// Text that the model wrote while it reasoned. It is not part of the reply.
    ReasoningText,
}

/// What the person can do about an error. Programs decide on the code; people
/// read the message.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum ErrorCode {
    /// A setting is absent or wrong, for example the API key. To try again
    /// does not help.
    Setup,
    /// The engine refused or failed the request. To try again can help.
    EngineFailed,
    /// A fault in this application.
    Internal,
}
```

Keep one empty line below these lines.

### 4. Five tests

Add between the test `turn_started_json` and the test `turn_completed_json`:

```rust
    #[test]
    fn content_delta_json() {
        assert_json(
            EventKind::ContentDelta {
                stream_kind: StreamKind::AssistantText,
                delta: "Hel".to_owned(),
            },
            json!({
                "thread_id": "thread-1",
                "turn_id": "turn-1",
                "type": "content.delta",
                "stream_kind": "assistant_text",
                "delta": "Hel",
            }),
        );
    }

    #[test]
    fn reasoning_delta_json() {
        assert_json(
            EventKind::ContentDelta {
                stream_kind: StreamKind::ReasoningText,
                delta: "The person asks".to_owned(),
            },
            json!({
                "thread_id": "thread-1",
                "turn_id": "turn-1",
                "type": "content.delta",
                "stream_kind": "reasoning_text",
                "delta": "The person asks",
            }),
        );
    }

    #[test]
    fn item_completed_json() {
        assert_json(
            EventKind::ItemCompleted {
                text: "Hello".to_owned(),
            },
            json!({
                "thread_id": "thread-1",
                "turn_id": "turn-1",
                "type": "item.completed",
                "text": "Hello",
            }),
        );
    }

    #[test]
    fn runtime_error_json() {
        assert_json(
            EventKind::RuntimeError {
                code: ErrorCode::EngineFailed,
                message: "the engine closed the connection".to_owned(),
            },
            json!({
                "thread_id": "thread-1",
                "turn_id": "turn-1",
                "type": "runtime.error",
                "code": "engine_failed",
                "message": "the engine closed the connection",
            }),
        );
    }

    #[test]
    fn each_error_code_json() {
        assert_eq!(
            serde_json::to_value(ErrorCode::Setup).unwrap(),
            json!("setup")
        );
        assert_eq!(
            serde_json::to_value(ErrorCode::EngineFailed).unwrap(),
            json!("engine_failed")
        );
        assert_eq!(
            serde_json::to_value(ErrorCode::Internal).unwrap(),
            json!("internal")
        );
    }
```

Keep one empty line above and below these lines.
