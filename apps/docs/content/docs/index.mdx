---

opensomething is a desktop application, written in Rust, that runs a team of
AI bots on your own computer.

Each bot is a persona around an agent engine: an ACP agent CLI or a chat API.
The application owns the conversations, the hand-offs between bots, the
approvals, the memory and the schedules. The engine only runs turns. Your keys
and your conversations stay on your computer.

## Status

The project is early. The desktop window opens with a chat on a background
that you can change, and it echoes each line that you send. No bot feature is
built yet. The [roadmap](./project/roadmap.mdx) shows what comes next.
