The window has two plain panes: the sidebar and the chat. A picture fades
into the top of the sidebar. You can change the picture.

## Change the picture

1. Click **You** at the bottom of the sidebar, then click **Settings**. You
   can also press Ctrl+, to open the settings.
2. On the page **This computer**, find the row **Sidebar picture**.
3. Click a round swatch. The picture changes immediately.

| Picture | Colour mode |
| --- | --- |
| Meadow | Dark |
| Dusk | Dark |
| Ocean | Dark |
| Dawn | Light |
| Plain | Follows the system |

Each picture sets the colour mode, so the text stays readable.

<Callout type="warn">
  The application does not save your choice yet. After a restart, the
  picture is Dawn again.
</Callout>
