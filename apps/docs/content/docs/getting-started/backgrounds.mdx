The chat is in a glass panel on a background. You can change the background.

## Change the background

Click a round swatch at the top right of the window. The background changes
immediately.

| Background | Colour mode |
| --- | --- |
| Meadow | Dark |
| Dusk | Dark |
| Ocean | Dark |
| Dawn | Light |
| Plain | Follows the system |

Each background sets the colour mode, so the text stays readable.

<Callout type="warn">
  The application does not save your choice yet. After a restart, the
  background is Meadow again.
</Callout>
